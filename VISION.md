# Factory vision

Software owners need a repeatable path from a scoped issue to a checked, independently reviewed candidate without losing control of their repository, credentials or delivery.

Factory retains the ADLC skills, explicit Foundation adoption, and the project Inbox. Codex owns native sessions, execution, tools, permissions, history and recovery in the first integration. GitHub owns issues, pull requests and CI. The npm entrypoint connects those owners and shows their actual state.

Factory does not own an agent loop, scheduler, context or retry engine, provider registry, cloud deployment, or autonomous publication. Self-improvement may propose bounded fixes; it cannot silently change this vision or expand authority.

Admit a feature only for a proven problem within this scope. Prefer native capability, configuration or a skill; choose the least maintenance needed; define an observable acceptance check. A scope change needs an explicit owner decision.
