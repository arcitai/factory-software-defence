# ADLC skills

This directory is the canonical catalog. Native Factory setup stages the skills
in its dedicated Codex home. `factory kit --output NEW_DIRECTORY` instead exports
them into `.agents/skills/` for deliberate adoption with an existing harness.
Neither route copies personal settings or grants access.

| Skill | Use |
| --- | --- |
| [Triage](factory-triage/SKILL.md) | Check vision fit, scope, duplicates and missing information |
| [Specify](factory-spec/SKILL.md) | Define intended behavior and meaningful acceptance |
| [Implement](factory-implement/SKILL.md) | Build and verify the accepted change |
| [Review](factory-review/SKILL.md) | Independently assess the actual candidate |
| [Security](factory-security/SKILL.md) | Investigate an explicitly scoped security question |
| [Evaluate](factory-evaluate/SKILL.md) | Compare configurations with retained evidence and honest costs |

Six skills do not imply six agents or execution stages. The harness owns tools,
context and execution. Factory Foundation is operator setup guidance, separate
from this catalog; read it with `factory foundation`.
