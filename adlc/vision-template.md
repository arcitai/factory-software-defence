# Project vision — owner review needed

Who has the problem, and what outcome should this project provide?

Which existing components and owners are retained? What is outside scope?

For a proposed feature: identify a proven in-scope problem, prefer an existing native capability, configuration or skill, keep maintenance small, and name an observable acceptance check. An unclear or out-of-scope proposal needs an owner decision. This template is staged only when the project has no existing explicit product brief.
